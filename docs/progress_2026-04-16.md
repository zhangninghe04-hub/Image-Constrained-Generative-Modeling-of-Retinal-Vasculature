### 3. Constraint Extraction (`src/constraint_extraction/extract_constraints.py`)
Implemented full image analysis pipeline on the 15 healthy fundus images:

| Function | Description |
|----------|-------------|
| `detect_retina_boundary()` | Detects circular FOV from black background |
| `detect_optic_disc()` | Brightness + morphology; clamped to anatomical size range |
| `detect_macula()` | Estimated from OD position; refined by dark-region search |
| `segment_vessels()` | CLAHE contrast enhancement + top-hat morphological filtering |
| `extract_vessel_orientation()` | Angular histogram of vessel pixels in annular zone around OD |
| `compute_vessel_density_map()` | 20×20 grid of relative vessel pixel density |
| `extract_all_constraints()` | Unified function returning pixel + normalized coordinates |

Sample output on `01_h.jpg`:
- Retina radius: 1661 px
- Optic disc: radius 249 px (ratio 0.150), normalized root = (0.184, −0.438)
- Macula: detected ~0.49 retina radii from OD
- Superior arcade: 42°, inferior arcade: −178°

### 4. Generative Model Extensions (`src/generative_models/branching_model.py`)

**`TreeGeneratorConfig.from_constraints()`**
- New class method to parameterize the generator directly from image-derived constraints
- Accepts output of `extract_all_constraints()` and maps to model config

**`ConstrainedTreeGenerator`** (new class)
- Extends baseline with density-aware branching depth modulation
- Local vessel density from the density map modulates effective `max_depth` per location
- High-density regions permit up to +2 extra branching levels; low-density regions are pruned earlier

## Validation Results (01_h.jpg)

| Model | Edges | Terminals | Total Length | Coverage Score | Fractal Dim |
|-------|-------|-----------|-------------|----------------|-------------|
| Baseline | 61 | 29 | 4.234 | 0.0095 | 0.546 |
| Image-Constrained | 106 | 52 | 7.299 | 0.0122 | 0.543 |
| Density-Aware | 106 | 52 | 7.299 | 0.0122 | 0.543 |

The image-constrained model generates ~70% more edges and terminals than the baseline,
reflecting the actual optic disc position and vessel arcade orientations extracted from
the image rather than manually specified defaults.
